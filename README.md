# Sakila Movie Search

Учебное приложение для поиска фильмов в демонстрационной базе данных MySQL
[`sakila`](https://dev.mysql.com/doc/sakila/en/). Проект предоставляет два
интерфейса к общей логике: консольное меню и веб-приложение на FastAPI.
История поисковых запросов сохраняется в MongoDB и используется для вывода
последних и наиболее популярных запросов.

## Возможности

- поиск фильмов по части названия;
- поиск по жанру и диапазону годов выпуска;
- постраничный вывод результатов по 10 фильмов;
- кеширование уже просмотренных страниц в консольной версии;
- сохранение истории успешных запросов в MongoDB;
- вывод пяти популярных и пяти последних запросов;
- консольный интерфейс с цветным форматированием;
- веб-интерфейс на FastAPI и Jinja2;
- единая обработка недоступности MySQL и MongoDB;
- раздельное журналирование сообщений `DEBUG`, `INFO` и `ERROR`.

## Технологии

- Python 3.10+
- MySQL и база данных `sakila`
- MongoDB
- FastAPI и Jinja2
- MySQL Connector/Python
- PyMongo
- Colorama, Colorlog и Tabulate
- Pytest

## Архитектура

```text
PROJECT_KUZAN/
├── main.py                       # точка входа консольной версии
├── app.py                        # FastAPI-приложение
├── config/
│   └── local_settings.py         # локальные настройки (не хранится в Git)
├── database/
│   ├── connection.py             # создание соединения с MySQL
│   ├── executor.py               # выполнение SELECT-запросов
│   ├── film_service.py           # операции поиска фильмов
│   ├── mongo_history_write.py    # запись и чтение истории MongoDB
│   └── queries.py                # параметризованные SQL-запросы
├── ui/
│   ├── console.py                # главное меню и сценарии поиска
│   ├── input_helpers.py          # ввод и проверка данных
│   ├── pagination.py             # постраничный вывод
│   └── history_view.py           # вывод истории в консоли
├── utils/
│   ├── exceptions.py             # исключения приложения
│   └── logger_config.py          # настройка журналирования
├── templates/                    # Jinja2-шаблоны веб-интерфейса
├── static/                       # CSS, JavaScript и изображения
├── tests/                        # тесты и диагностические проверки
└── logs/                         # журналы работы (не хранится в Git)
```

Оба интерфейса используют общий слой `database`:

```text
main.py → ui → database → MySQL / MongoDB
app.py  ─────→ database → MySQL / MongoDB
```

Пользовательский интерфейс не выполняет SQL напрямую. Модуль
`film_service.py` предоставляет операции предметной области, `connection.py`
создаёт соединения, `executor.py` выполняет запросы, а `queries.py` хранит их
текст.

## Требования

Перед запуском потребуются:

1. Python версии 3.10 или новее.
2. Доступный сервер MySQL с установленной базой `sakila`.
3. Доступный сервер MongoDB и строка подключения с правами чтения и записи.

## Установка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone <repository-url>
cd PROJECT_KUZAN
```

Создайте и активируйте виртуальное окружение.

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Linux или macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install mysql-connector-python pymongo colorama colorlog tabulate fastapi uvicorn jinja2 pytest httpx
```

## Конфигурация

Создайте каталог `config`, если он отсутствует, и файл
`config/local_settings.py`:

```python
dbconfig = {
    "host": "localhost",
    "port": 3306,
    "user": "your_mysql_user",
    "password": "your_mysql_password",
    "database": "sakila",
}

MONGODB_URL_WRITE = "mongodb://localhost:27017"
MONGODB_URL_READ = MONGODB_URL_WRITE
MONGODB_URL_ATLAS = MONGODB_URL_WRITE
```

Названия базы и коллекции истории задаются константами `DB_NAME` и
`COLLECTION_NAME` в `database/mongo_history_write.py`.

> Никогда не добавляйте `config/local_settings.py` с настоящими паролями в
> Git. Каталог `config/` уже исключён через `.gitignore`.

## Запуск консольной версии

Из корневого каталога проекта выполните:

```bash
python main.py
```

Главное меню позволяет искать фильмы, просматривать статистику запросов и
завершать программу командой `q`.

## Запуск веб-версии

Запустите сервер разработки:

```bash
python -m uvicorn app:app --reload
```

Откройте в браузере:

```text
http://127.0.0.1:8000
```

Основные маршруты:

| Маршрут | Назначение |
|---|---|
| `/` | форма поиска |
| `/search` | результаты поиска |
| `/popular` | популярные запросы |
| `/recent` | последние запросы |

Интерактивная документация FastAPI доступна по адресу
`http://127.0.0.1:8000/docs`.

## Тестирование

Веб-тесты используют подмену обращений к внешним сервисам и запускаются так:

```bash
python -m pytest tests/test_web.py -v
```

Файлы `tests/test_connection.py` и `tests/test_mongo.py` содержат
диагностические проверки подключений. Перед их запуском изучите содержимое:
некоторые проверки требуют доступных внешних сервисов и могут записывать
тестовые документы в MongoDB.

## Обработка ошибок

Ошибки недоступности MySQL и MongoDB преобразуются в единое исключение
`ServiceUnavailableError`. Консольный и веб-интерфейсы показывают понятное
сообщение, а технические сведения сохраняются в журнале.

Ошибки MongoDB при сохранении истории не прерывают основной поиск фильмов.
Ошибки выполнения SQL передаются интерфейсу через исключения
`mysql.connector`.

## Журналы

При запуске консольной версии автоматически создаётся каталог `logs`:

```text
logs/
├── debug.log
├── info.log
└── errors.log
```

Каталог исключён из Git и предназначен только для локальной диагностики.

## Безопасность

- SQL-запросы используют параметры `%s`; пользовательские значения не
  вставляются в SQL конкатенацией строк.
- Пароли и строки подключения должны храниться только в локальном файле
  `config/local_settings.py` или в переменных окружения.
- Перед публикацией репозитория убедитесь, что секреты отсутствуют в истории
  Git, логах и тестовых данных.

## Ограничения

- проект рассчитан на структуру демонстрационной базы MySQL `sakila`;
- история поиска зависит от доступности настроенной MongoDB;
- встроенная аутентификация пользователей отсутствует;
- сервер Uvicorn с параметром `--reload` предназначен только для разработки.
